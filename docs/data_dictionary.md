# Data Dictionary

Phase 3 does not assume a city or source schema because Phase 2 has not yet selected and acquired real datasets. The pipeline accepts normalized CSV columns such as `timestamp`, `latitude`, `longitude`, `road_id`, `vehicle_count`, `average_speed`, `energy_consumption`, and `demand` when those columns are present.

The generated reports record the actual columns, dtypes, missingness, ranges, and features for each input file.
