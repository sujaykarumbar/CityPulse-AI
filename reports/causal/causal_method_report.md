# Causal method report

This system supports a transparent evidence hierarchy:

1. randomized experiment
2. strong quasi-experiment
3. well-supported observational design
4. observational association
5. prediction-only evidence

The causal layer does not silently convert an association into a causal estimate.

Available design primitives include difference-in-differences, event study, synthetic control, interrupted time series, propensity methods, matching, doubly robust estimation, and RD structures when a threshold exists.
