# Mobility Data Scope

No verified mobility dataset is currently present in this checkout. The Phase 9 pipeline accepts aggregated OD data or trip records only when supplied by a legitimate source.

Required provenance fields for a real dataset:

- Dataset and source URL
- License and usage terms
- Geographic and temporal coverage
- Spatial and temporal granularity
- Units and important fields
- Known limitations and privacy constraints

Until those fields are documented from the source, mobility demand, OD flows, transit statistics, forecasts, and correlations are `NOT MEASURED`.
